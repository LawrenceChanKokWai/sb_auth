
## Authorization Server (Spring Boot)
## Section 1

### Dependencies used:
1. Eureka Discovery Client
2. OAuth2 Authorization Server
3. PostgresSQL Driver
4. Spring Data JPA
5. Lombok
6. Spring Web
7. totp (QR Code Setup)
8. yauaa (For getting user login devices information)

### Build Tool and versions used:
1. Maven
2. Spring boot 3.5.3
3. Java 21

### resources (setup)
1. keys folder (For holding rsaKeys-public and private)
2. data folder (For storing schema)
3. Configuration files (application.yml, application-dev.yml, application-test.yml, application-prod.yml)
